# プリンター 費用シミュレーター

接客時に、プリンターの機種ごとの「本体価格＋インク代」の累計を比べて、どれがいつ安くなるかをその場で見せるWebツール。
本体価格・インク全色セットの値段・1セットの印刷可能枚数と、お客様のインク購入ペースを入れると、累計費用が逆転するまでの年数が出る。

- サーバー不要の静的サイト（バニラ HTML / CSS / JS、1ファイル）。入力内容はどこにも送信されない
- 公開URL: https://printer-ink.mnlight.dev （GitHub Pages）

## 使い方

1. 各機種の「本体価格」「インク全色セット価格」「1セットで印刷できる枚数」を入力（枚数はカタログのカラー基準の値）
   - 初期値はエコタンク／ファーストタンク／カートリッジの例。実際の商品の数字で上書きする
   - 機種名の見出しは打ち替えられる（ギガタンクなどメーカーごとの呼び名に合わせられる）
   - 「×」で機種を外す、「＋ 機種を追加」で増やす。**最大3機種**（後述）
2. 「インクはどのくらいの頻度で買われますか？」に、今お使いの機種での購入ペースを入力
   - 「1年に □ 回」と「□ 年に1回」は連動するので、お客様の言い方そのままで入れてよい
3. 「約 ○年○ヶ月で逆転」と、全機種の累計費用グラフが出る。グラフは触ると各時点の金額が出る
4. 「数値の表を見る」で、購入時〜10年後の累計を表で確認できる（各年の最安が緑）

## 比較の基準

一番右の機種が「**比較の基準**」で、他の機種はすべてこれと比べた逆転年数が出る。
一番安いカートリッジ機を基準に置いて、そこから高い機種に替えると何年で回収できるかを見せる想定。
今お使いの機種がある場合は、この欄にその機種の数字を入れればそのまま乗り換えの話になる。

## 計算方法

印刷可能枚数から、同じ印刷量を各機種でこなした場合のインク代を求めている。

```
年間印刷枚数   = 基準機種の印刷可能枚数 × 年間のインク購入回数
各機種の年間セット数 = 年間印刷枚数 ÷ その機種の印刷可能枚数
逆転までの年数 = 本体価格の差 ÷ 1年あたりのインク代の差
```

例：エコタンク 39,800円 / インク 4,500円 / 6,000枚、カートリッジ 15,800円 / 5,000円 / 800枚、年1回購入
→ 年800枚の印刷。エコタンクのインクは約7.5年に1回で済むので年間インク代は600円 対 5,000円。
本体差24,000円 ÷ 年差4,400円 = **約5年5ヶ月で逆転**、10年で20,000円お得。

## なぜ3機種までか

グラフの線を色だけで見分けられる上限が3色だから（4色目はオレンジや青と区別がつかなくなる）。
色は blue / aqua / orange を使っていて、この3色は色覚特性のある人でも見分けられることを検証済み（ライト・ダーク両モード）。

## 注意

- 本体に付属するインクは計算に含めていない（含めると大容量インクの機種がさらに有利になるので、控えめな数字が出る）
- 印刷可能枚数はカタログ値。写真印刷が多い場合など、使い方で実際の枚数は変わる
- 印刷可能枚数は黒／カラーを分けず、カラー基準の1つの値で計算している
