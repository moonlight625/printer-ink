# エコタンク vs カートリッジ 費用シミュレーター

接客時に、エコタンク（インクボトル補充）と従来のカートリッジ機のどちらが得かを、その場で計算して見せるWebツール。
本体価格・インク全色セットの値段・1セットの印刷可能枚数と、お客様のインク購入ペースを入れると、累計費用が逆転するまでの年数が出る。

- サーバー不要の静的サイト（バニラ HTML / CSS / JS、1ファイル）。入力内容はどこにも送信されない
- 公開URL: https://printer-ink.mnlight.dev （GitHub Pages）

## 使い方

1. 2機種の「本体価格」「インク全色セット価格」「1セットで印刷できる枚数」を入力（枚数はカタログのカラー基準の値）
2. 「インクはどのくらいの頻度で買われますか？」に、今お使いのカートリッジ機での購入ペースを入力
   - 「1年に □ 回」と「□ 年に1回」は連動するので、お客様の言い方そのままで入れてよい
3. 「約 ○年○ヶ月で逆転」と、累計費用のグラフが出る。グラフは触ると各時点の金額と差額が出る
4. 「数値の表を見る」で、購入時〜10年後の累計を表で確認できる

初期値は例なので、実際の商品の数字で上書きする。「初期値に戻す」で戻る。

## 計算方法

印刷可能枚数から、同じ印刷量をエコタンクでこなした場合のインク代を求めている。

```
年間印刷枚数   = カートリッジの印刷可能枚数 × 年間のインク購入回数
エコタンクの年間セット数 = 年間印刷枚数 ÷ エコタンクの印刷可能枚数
逆転までの年数 = 本体価格の差 ÷ 1年あたりのインク代の差
```

例：本体 39,800 / 15,800円、インク 4,500 / 5,000円、枚数 6,000 / 800枚、年1回購入
→ 年800枚の印刷。エコタンクのインクは約7.5年に1回で済むので年間インク代は600円 対 5,000円。
本体差24,000円 ÷ 年差4,400円 = **約5年5ヶ月で逆転**、10年で20,000円お得。

### 注意

- 本体に付属するインクは計算に含めていない（含めるとエコタンクがさらに有利になるので、控えめな数字が出る）
- 印刷可能枚数はカタログ値。写真印刷が多い場合など、使い方で実際の枚数は変わる
- 印刷可能枚数は黒／カラーを分けず、カラー基準の1つの値で計算している
